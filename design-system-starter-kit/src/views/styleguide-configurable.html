Not configurable

These appeared in the full styleguide but can't be assembled by an admin without a custom LWC/Aura component or custom CSS:

  • Toggle switches (checkbox fields render as checkboxes)
  • Standalone badges, pills, avatars, spinners, progress rings/bars as decorative elements
  • Custom status colours (e.g. green/amber/red "Vaccinated/Overdue" badges)
  • Manually placed alerts, toasts, and empty-state illustrations
  • Custom fonts, arbitrary component colours, and free-form layouts/grids
  • Editable multi-row grids for creating new records (use a Screen Flow instead)
